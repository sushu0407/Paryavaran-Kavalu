Project Title - Paryavaran Kavalu 

Project Description
Paryavaran Kavalu is an Android application developed to promote environmental awareness and help users report environmental issues efficiently. The application provides a modern and user-friendly interface with location support, image handling, and organized data management for a better user experience.

Features
- Modern UI built using Jetpack Compose
- Environmental issue reporting system
- Google Maps integration
- User profile management
- Wishlist and saved items functionality
- Image compression support
- Responsive and clean application design
- Organized navigation system

Tech Stack
- Kotlin
- Jetpack Compose
- Android Studio
- Google Cloud
- Google Maps API
- Image Compression
- Material Design
- Gradle

 Installation Steps
1. Clone the repository
2. Open the project in Android Studio
3. Sync Gradle files
4. Add the Google Maps API key
5. Build and run the application

Run Instructions
Run the application using:
- Android Emulator
- Physical Android device with USB debugging enabled
